# Bundled runtime assets

- `dump7_xyzi_clean.pcd`: default static map used by the replay UI.
- `g1_description/g1_29dof_rev_1_0.urdf`: default 29-DoF G1 model.
- `g1_description/meshes/`: the 35 STL files referenced by that URDF.

The paths are resolved relative to the Python source directory, so moving or
cloning the project does not require path changes.
